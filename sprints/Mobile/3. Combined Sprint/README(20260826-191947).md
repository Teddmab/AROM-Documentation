# MOB-03 — Role-Specific Homes

Implement the five home pages shown in `references/role-homes.png` using one shared configurable shell.

## Scope

- Administrateur, Agent de collecte, Production, Gestionnaire de stock, Ventes & Boutique.
- Shared header, role chip, campaign, sync state, notifications and bottom navigation.
- Role-specific hero, KPIs, primary actions and next-work card.
- Loading, empty, offline, error and unauthorized-role states.

## Acceptance

- Server permissions determine available actions.
- One shared screen system; no five duplicated implementations.
- Correct role label and data for every role.
- 48 dp targets, font scaling, safe areas, low-end Android image optimization.
- Tests cover all roles and permission combinations.
