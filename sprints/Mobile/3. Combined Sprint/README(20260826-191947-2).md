# MOB-04 — Shared Actions, Notifications, Activity and Sync

Implement `references/shared-operations.png`.

## Scope

- Permission-aware quick-action sheet.
- Notifications with actionable items.
- Campaign selector.
- Activity timeline.
- Synchronization centre and failure-detail sheet.
- Pending, syncing, synchronized and failed states.

## Acceptance

- Quick actions reflect server permissions.
- Activity and sync states use real persisted data.
- Retry is idempotent and prevents duplicate submissions.
- Failed local records are never silently discarded.
- Campaign switch refreshes scoped data safely.
- Tests cover actions, filters, offline retry and failure states.
