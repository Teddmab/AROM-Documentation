# MOB-06 — Owner Commercial and Payment Oversight

Implement the six-screen flow in `references/owner-commercial.png`.

## Flow

1. Commercial overview
2. Orders and sales
3. Payment monitoring
4. Customer balance detail
5. Collection follow-up assignment
6. Updated follow-up state

## Acceptance

- Mode Administrateur appears throughout.
- Stock, order, payment and receivable totals use authoritative data.
- Customer balances reconcile with payments.
- Follow-up assignment is permission-controlled and auditable.
- Loading, empty, offline/stale and error states exist.
- Tests cover drill-down, totals and assignment.
